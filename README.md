# Gov-KS-Sedgwick-County

Public, sourced facts about Sedgwick County, Kansas government for Runtime Republic members and their AI assistants.
Personal finance AIs read these files to estimate the taxes on bills and receipts, and the dashboard uses them to rank the four budgets: Federal, State, Local and Family.

Level: local. Read DATA-RULES.md before changing anything.

| File | Holds |
|---|---|
| data/tax-rates.csv | Tax rates and fees, with sources |
| data/offices.csv | Offices, officeholders, terms and official contacts |
| data/deadlines.csv | Election, registration and candidate-filing deadlines |
| data/debt.csv | Government debt, with as-of dates |
| data/recipients.csv | Funds and agencies that receive the money |
